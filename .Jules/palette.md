## 2024-05-15 - Missing form associations in shadcn/ui custom layouts
**Learning:** When manually composing form layouts with `shadcn/ui` components (like `<Input>` and `<label>`), they do not automatically associate themselves for accessibility. Relying only on `className` for styling leaves screen readers without context, and clicking labels won't focus the inputs. Also, helper text often gets visually placed near inputs but isn't programmatically linked.
**Action:** Always explicitly add `htmlFor` to `<label>` and a matching `id` to the corresponding `<Input>`. Use `aria-describedby` on the `<Input>` to reference the `id` of any helper text element (e.g., `<p id="helper-id">`). If a visible label is intentionally omitted (like in table rows or top-level search bars), explicitly define an `aria-label` for screen reader accessibility.
