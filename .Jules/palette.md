## 2025-06-20 - Accessible Form and Table Inputs
**Learning:** In complex forms using `shadcn/ui` components without explicitly linked labels, screen readers may fail to associate inputs with their purpose. Furthermore, in data tables with repeating row elements (like "Себестоимость" inputs or action buttons), non-unique `aria-label`s create a confusing, ambiguous experience for users utilizing assistive tech.
**Action:** Always strictly link `<label>` and `<Input>` elements using `htmlFor` and `id` respectively. For helper text, utilize `aria-describedby` referencing the helper `<p>`'s `id`. Crucially, when repeating interactive components across mapped elements (e.g., table rows), inject contextual, unique dynamic strings into `aria-label`s (like \`Себестоимость для ${product.title}\`) so screen readers can uniquely identify each target.
