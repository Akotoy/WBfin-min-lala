## 2024-07-01 - Dynamic ARIA Labels in Data Tables and Form Associations
**Learning:** For complex data tables with repeating interactive elements (like cost inputs or price adjustment buttons per row), standard generic inputs lack context for screen readers. Additionally, shadcn/ui forms require explicit HTML label associations (`htmlFor` and `id`) and `aria-describedby` for helper text, as they are not always implicitly connected depending on the DOM structure.
**Action:** Always use dynamic `aria-label`s referencing the row's specific context (like `product.title`) when creating interactive elements within a table loop. Ensure `<label>` and `<Input>` components are explicitly linked using `htmlFor` and `id` attributes respectively, and add `aria-describedby` to inputs when helper text is present.
