## 2024-06-18 - [Accessibility in Repeating Table Elements]
**Learning:** When building complex data tables with repeating interactive elements (e.g., inputs or buttons per row), relying on static ARIA labels or table headers alone is insufficient for screen readers. Users lose context when tabbing through identical inputs (like "Cost") across multiple rows. Additionally, visual indicators like colors (e.g., red text for low stock) are not announced by screen readers.
**Action:** Always use dynamic `aria-label`s for interactive elements within lists or tables, explicitly referencing the row's specific context (e.g., `aria-label={\`Себестоимость для \${product.title}\`}`). Provide visually hidden (`sr-only`) fallback text for critical state changes that are only communicated visually (e.g., `<span className="sr-only">Мало на складе: </span>` for low stock items).
