## 2024-05-18 - Accessibility Improvements in Shadcn Forms and Tables
**Learning:** When using shadcn UI components, it is critical to explicitly associate `<label>` with `<Input>` using `htmlFor` and `id`. Additionally, helper text must be linked to the relevant input using `aria-describedby` so screen readers announce it when the input receives focus. In repeating data structures like tables, inputs and icon buttons must have dynamic `aria-label` attributes (e.g. `aria-label={`Себестоимость для ${product.title}`}`) to provide specific context, otherwise screen readers will just read "Edit" or "0" multiple times without distinguishing which row is being acted upon.
**Action:** Always check shadcn forms to verify that `htmlFor`/`id` mapping exists. Add `aria-describedby` where helper text is present. Ensure repeating table elements use dynamically generated `aria-label`s reflecting their row context.
