## 2024-05-24 - Accessibility Enhancements for Forms and Tables
**Learning:** In a React application using `shadcn/ui` components, standard `<label>` tags must explicitly use the `htmlFor` attribute associated with an `<Input>` component's `id` to ensure screen readers announce them properly. If helper text is present, `aria-describedby` should link the input to the paragraph ID of the helper text. Additionally, when using data tables with row-specific interactive elements (inputs or action buttons), it is critical to provide dynamic `aria-label` attributes containing context from the specific row (e.g., `aria-label={`Себестоимость товара ${product.title}`}`). This prevents screen readers from simply announcing "Input" or "Button" without the necessary context.
**Action:** When implementing forms, always ensure explicit label associations (`htmlFor` + `id`) and use `aria-describedby` for helper text. For repeating interactive components in lists or tables, assign a dynamic `aria-label` based on the row's primary contextual value (like the item's name or title).
