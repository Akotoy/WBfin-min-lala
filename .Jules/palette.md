## 2024-05-24 - Explicit Form Accessibility with shadcn/ui
**Learning:** When using shadcn/ui components (like `Input`) with standard `<label>` elements, screen readers often fail to associate them if they only rely on visual proximity or DOM nesting. Explicitly linking them using `htmlFor` on the label and `id` on the input is critical for accessibility. Furthermore, helper text providing context (like "Пример: 6 для УСН 6%") must be explicitly linked using `aria-describedby` on the input, pointing to the `id` of the helper text element, otherwise screen reader users miss crucial validation context.
**Action:** Always verify that every `<label>` has a `htmlFor` attribute matching the `id` of its corresponding `<Input>`. For inputs with helper text or error messages, always use `aria-describedby` to link them.
