## 2024-05-24 - Accessibility improvements for inputs and dynamic tables
**Learning:** In complex data tables or forms, `shadcn/ui` components for inputs and buttons must have explicit associations to be accessible to screen readers. For forms, explicitly link `<label>` and `<Input>` using `htmlFor` and `id` attributes respectively, and use `aria-describedby` for helper text. For repeating interactive elements in data tables (e.g., inputs or buttons per row), dynamic `aria-label`s must be added referencing the row's specific context (like `product.title`) to prevent ambiguous announcements.
**Action:** Always link `<label>` and inputs, and use dynamic `aria-label` attributes on inputs and buttons inside list or table row maps to ensure screen reader users have proper context.
